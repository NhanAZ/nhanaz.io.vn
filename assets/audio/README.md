# Article recordings

Vietnamese narration uses the Thái Sơn preset from [VieNeu-TTS v3 Turbo](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo), by the VieNeu-TTS contributors, distributed under Apache 2.0. English narration uses the Heart preset from [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M), by hexgrad, distributed under Apache 2.0. The inference wrapper [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) is MIT licensed.

Vietnamese inference also uses [MOSS-Audio-Tokenizer-Nano-ONNX](https://huggingface.co/OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano-ONNX), by the OpenMOSS Team, distributed under Apache 2.0.

These MP3s are synthesized recordings of NhanAZ's articles. They are not recordings of the website author. Model weights and voice reference assets are not redistributed here. Exact model revisions or hashes, article text hashes, voice names, file checksums, durations, and chapter offsets are recorded in `index.json`.

Operational instructions are in `docs/article-audio.md` in the source repository.
