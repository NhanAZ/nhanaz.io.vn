Privacy

A plain explanation of what this site sees, stores, and does not do with your data.

A static website

Less data is also a design decision.

nhanaz.io.vn is a static website whose source is kept on GitHub and whose production version is currently delivered through Vercel. GitHub Pages still has a workflow that creates a fallback static build, but the main domain does not point to GitHub Pages. The site has no user accounts, login form, or shop. Technical logs kept by Vercel, GitHub, Cloudflare, or a network provider are governed by those providers’ own policies.

The site has a public view counter for page paths. It stores a normalized path and its count in Upstash Redis through a Vercel API. To limit requests, the API also keeps a short-lived hash of the request identity, not a raw IP address. The counter does not store page contents, accounts, email addresses, or personal profiles.

When Vercel Speed Insights is enabled on production, the browser loads a Vercel script to send page-load performance and Core Web Vitals measurements. Vercel processes that data under its own policies. The site does not use Speed Insights to create accounts, serve advertising, or read what you type.

Your browser may store the light or dark theme in localStorage under nhanaz-color-theme. When you switch languages between paired articles, the script may use sessionStorage briefly to restore your reading position and then remove that data. Those mechanisms stay on your device and are not sent to my server.

Some articles include Giscus comments. Opening that area loads resources from giscus.app, and comments go through GitHub Discussions. That external service may have its own cookies, logs, and privacy policy. You can leave the comment area closed if you do not want the browser to request it.

Links to GitHub, Zalo, and Telegram also take you away from this website. Check each service’s policy before sending information. If you need to ask about data or report a privacy concern, use the contact page. This page describes the current site and will change if the way it handles data changes.
