# NhanAZ site context

Use this skill when a question concerns Nguyễn Thành Nhân, NhanAZ, the public project archive, PocketMine-MP, Minecraft Bedrock writing, study notes, or published milestones.

## Source order

1. Start with `https://nhanaz.io.vn/llms.txt`.
2. Follow the canonical page link and read the page itself before quoting a detail.
3. Use `https://nhanaz.io.vn/llms-full.txt` for broader context and `https://nhanaz.io.vn/sitemap.xml` for public URL coverage.
4. Treat first-person memories and criticism as the writer's perspective, not as neutral third-party fact.
5. Do not infer private information beyond what the archive intentionally publishes.

The site exposes public GET resources and an aggregate page-view counter. It has no account, private data surface, or content-writing operation.
