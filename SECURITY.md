# Security policy

This repository contains the source and deployment configuration for `nhanaz.io.vn`.

If you find a vulnerability in the current site or its deployment, use GitHub's private
[Report a vulnerability](https://github.com/NhanAZ/nhanaz.io.vn/security/advisories/new) form.
Please do not publish exploit details in Discussions.

Only the current `main` branch and the live site are maintained. Archived branches are kept as historical snapshots.
