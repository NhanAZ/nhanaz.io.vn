# nhanaz.io.vn API context

This is the Markdown twin of [api/llms.txt](https://nhanaz.io.vn/api/llms.txt).

The public API is intentionally small and read-only. Use [openapi.json](https://nhanaz.io.vn/openapi.json) for the typed contract, [developers.md](https://nhanaz.io.vn/developers.md) for scope, [mcp](https://nhanaz.io.vn/mcp) for the read-only MCP surface, and [ask](https://nhanaz.io.vn/ask) for NLWeb-compatible search over the curated archive index.
